# Yuniors Chill Zone

The code behind **[yuniorschillzone.xyz](https://yuniorschillzone.xyz)** — a community
hangout with chat servers, voice channels, a video site, an image board, browser games
and a multiplayer piano.

Built with plain HTML, CSS and JavaScript — no frameworks, no build step. Supabase
handles accounts, database, realtime and storage. Deployed with GitHub Pages.

## What's here

| Page | What it is |
|---|---|
| `index.html` | The main app — servers, text & voice channels, DMs, friends, profiles, bots |
| `video.html` | VideoZone — videos and a vertical Shorts feed |
| `qmages.html` | Qmages — image board |
| `piano.html` | Multiplayer piano |
| `music.html` / `gaming.html` | Music room and browser games |

Shared pieces: `ycz-theme.css` (theme), `ycz-i18n.js` (English / Español / Français /
Português), `ycz-icons.js` (SVG icons).
